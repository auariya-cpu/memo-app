ภาษาไทย

เสียงและข้อความ: การถอดเสียงทำงานบนอุปกรณ์ของผู้ใช้ทั้งหมด เสียงจากไมโครโฟนไม่ถูกส่งออกจากเครื่องและไม่ถูกบันทึกเป็นไฟล์เสียง ข้อความที่ถอดได้และบันทึกย่อเก็บเป็นไฟล์ .txt ในอุปกรณ์ของผู้ใช้เท่านั้น (Documents/Memo)

การดาวน์โหลดโมเดล: ครั้งแรกแอปดาวน์โหลดไฟล์โมเดลถอดเสียงจากเซิร์ฟเวอร์สาธารณะ (huggingface.co) แอปไม่ส่งข้อมูลส่วนตัวใดๆ ไปในคำขอนี้ และตรวจรุ่นโมเดลใหม่ไม่เกินวันละครั้งด้วยวิธีเดียวกัน

Google Drive (ไม่บังคับ): เมื่อผู้ใช้เปิดฟีเจอร์และเข้าสู่ระบบ Google แอปขอสิทธิ์ https://www.googleapis.com/auth/drive.file ซึ่งให้แอปเข้าถึงเฉพาะไฟล์ที่แอปสร้างเอง แอปอัปโหลดไฟล์ข้อความบันทึกไปยังโฟลเดอร์ "Memo" ใน Google Drive ของผู้ใช้เท่านั้น แอปไม่อ่านหรือเห็นไฟล์อื่นของผู้ใช้ ไม่เก็บรหัสผ่าน และไม่เก็บโทเค็นถาวร ผู้ใช้ยกเลิกได้ในแอป (ตั้งค่า → Google Drive) หรือที่ myaccount.google.com/permissions

การเก็บและแบ่งปันข้อมูล: ผู้พัฒนาไม่มีเซิร์ฟเวอร์ ไม่เก็บ ไม่เห็น และไม่แบ่งปันข้อมูลของผู้ใช้กับบุคคลที่สาม ไม่มีโฆษณาและไม่มีระบบวิเคราะห์การใช้งาน

การลบข้อมูล: ลบไฟล์ใน Documents/Memo ได้เอง การถอนการติดตั้งแอปจะลบโมเดลที่ดาวน์โหลดไว้ ไฟล์ใน Google Drive ลบได้จาก Drive โดยตรง

Google API Services User Data Policy: การใช้และการถ่ายโอนข้อมูลที่ได้รับจาก Google APIs ของ Memo เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

English

Audio and text: Speech recognition runs entirely on the user's device. Microphone audio never leaves the device and is not saved as an audio file. Transcripts and notes are stored only as .txt files on the user's device (Documents/Memo).

Model download: On first use the app downloads the speech model from a public server (huggingface.co). No personal data is sent in this request. The app checks for a newer model at most once a day in the same way.

Google Drive (optional): If the user enables it and signs in with Google, the app requests the scope https://www.googleapis.com/auth/drive.file, which only allows access to files the app itself creates. The app uploads the transcript text files to a folder named "Memo" in the user's own Google Drive. It cannot see or read any other file in the user's Drive, does not collect passwords, and does not persist access tokens. The user can disconnect in the app (Settings → Google Drive) or at myaccount.google.com/permissions.

Data collection and sharing: The developer operates no server and does not collect, view or share user data with third parties. The app has no ads and no analytics.

Deletion: Users can delete files in Documents/Memo at any time. Uninstalling the app removes the downloaded model. Files in Google Drive can be deleted directly in Drive.

Google API Services User Data Policy: Memo's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
